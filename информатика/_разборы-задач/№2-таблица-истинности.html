Что такое zip

Теперь самая неприятная строка:

Допустим, есть перестановка:

Она означает:

1 столбец — w
2 столбец — z

То есть в таблице написано:

w = ?

Если порядок столбцов такой:

w z y x

а строка такая:

1 0 1 0

то получается:

w = 1
z = 0
y = 1
x = 0

Вот именно это и делает zip.

zip(p, r)

соединяет элементы попарно:

p = ('w', 'z', 'y', 'x')
r = ( 1,   0,   1,   0 )

Получается:

('w', 1)
('z', 0)
('y', 1)
('x', 0)

То есть zip буквально “застёгивает молнию”: берёт первый элемент отсюда и первый элемент оттуда, потом второй и второй, потом третий и третий.

Простой пример:

names = ['x', 'y', 'z']
values = [10, 20, 30]

zip(names, values)

даст пары:

('x', 10)
('y', 20)
('z', 30)

Что такое dict

dict — это словарь.

Словарь хранит пары вида:

ключ: значение

Например:

student = {

'name' → 'Миша'

Было:

То есть словарь говорит:

Что такое ** перед словарём

Вот это:

** распаковывает словарь в аргументы функции.

Допустим, есть функция:

def f(x, y, w, z):
    return ...

И есть словарь:

{
    'w': 1,
    'z': 0,
    'y': 1,
    'x': 0
}

Тогда:

f(**{
    'w': 1,
    'z': 0,
    'y': 1,
    'x': 0
})

то же самое, что написать:

f(w=1, z=0, y=1, x=0)

А Python уже сам поймёт:

x = 0
y = 1
w = 1
z = 0

То есть ** нужен, чтобы передать значения в функцию по именам переменных.

Это важно, потому что порядок аргументов в функции может быть странный:

А словарь всё равно правильно сопоставит значения именно по именам.

  1. Строка return (not(((not (x)) or y) and (not(w)))) or (not(z and (not(y and w)))) меняется в зависимости от функции в условии
  2. Строка for a1,a2,a3,a4,a5,a6,a7 in product([0,1],repeat=7): меняется в зависимости от того сколько неизвестных в табличке. Если 7 - переменных тоже 7 и repeat = 7. Если какое-то другое число - кол-во переменных равно этому числу и повторов столько же.
  3. Строка t=[(0,a1,a2,1),(a3,1,a4,a5),(1,0,a6,a7)] меняется в зависимости от вида таблицы. Просто переписывайте табличку, фактически.
  4. Само условие и цикл далее НЕ меняется никогда, меняется только ==[0,0,0]:. Это зависит от функции F из условия. Если она равна во всех случаях 0 0 0 значит и тут ==[0,0,0]:. Если равна, например, 1 0 1 тогда у вас будет ==[1,0,1]:.

И это буквально все изменения от условия к условию, которые вам надо знать. Остальное не меняется буквально никогда.
