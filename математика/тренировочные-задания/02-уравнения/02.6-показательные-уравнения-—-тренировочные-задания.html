Подсказка

Слагаемое с “перевёрнутым” показателем вроде 41−x раскладывается через свойства степени: 41−x=4x41​=4x4​. После этого во всём уравнении остаётся только одна “новая переменная” t=4x, и уравнение превращается в обычное дробно-рациональное относительно t.

Пример попроще. 2x+22−x=6: перепишем 22−x=2x4​, введём t=2x>0: t+t4​=6⇒t2−6t+4=0 — обычное квадратное уравнение относительно t, а не что-то принципиально новое.

  1. Решите уравнение: 6⋅9x−13⋅6x+6⋅4x=0 (однородное уравнение — разделите на 4x и введите t=(3/2)x).

  2. Решите уравнение: 2x⋅3x+1=62x−1 (приведите обе части к возможно более удобному виду через основание 6).

  3. Решите уравнение: 5x+5−x=526​ (замена t=5x>0).

  4. Докажите, что уравнение 2x+3x=5x имеет единственный корень, и найдите его.

Подсказка

Если в уравнении есть несколько показательных слагаемых с разными основаниями, иногда помогает разделить обе части на самое “быстрорастущее” из них — тогда получившиеся дроби превращаются в убывающие функции, и остаётся понять, при каком x их сумма равна единице; при этом такая сумма строго убывает, поэтому если корень нашёлся (хотя бы подбором), он гарантированно единственный.

Пример попроще. 3x+4x=5x: разделим на 5x: (53​)x+(54​)x=1. При x=2 получаем 259​+2516​=2525​=1 — подходит (это просто теорема Пифагора для чисел 3,4,5, только записанная через показательное уравнение). А раз сумма двух убывающих функций сама строго убывает, других корней быть не может.

  1. При каком значении a уравнение 4x−a⋅2x+a+3=0 имеет ровно один корень?

  2. Решите уравнение: (2​)x2−2x=2x−1.

  3. Решите систему уравнений: {2x⋅3y=123x⋅2y=18​.

  4. Решите уравнение: 32x−4⋅3x+1+27=0.

  5. Найдите все значения a, при которых уравнение 9x−(a+2)⋅3x+2a=0 имеет два различных положительных корня x1​,x2​ (то есть уравнение относительно t=3x должно иметь два различных положительных корня).
